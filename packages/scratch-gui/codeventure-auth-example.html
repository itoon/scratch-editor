CodeVenture Authentication Integration

This page demonstrates how to integrate CodeVenture authentication with the Scratch Editor. When users click the "Scratch" menu in CodeVenture, they should be redirected to the Scratch Editor with authentication parameters.

URL Parameter Format

CodeVenture should redirect users to the Scratch Editor with the following URL format:

https://your-scratch-editor.com/?token=JWT_TOKEN&username=USERNAME&user_id=USER_ID&source=codeventure

Required Parameters:

  • token: JWT token from CodeVenture authentication
  • username: User's username
  • user_id: User's unique identifier
  • source: Must be "codeventure" to identify the source

Implementation Details

What Happens When User Arrives:

  1. The CodeVentureAuthHOC parses URL parameters
  2. Token and user data are validated
  3. If validation passes, user is automatically authenticated
  4. Sensitive URL parameters are removed for security
  5. User sees their name in the menu bar with "CV" indicator

Menu Bar Display:

When authenticated via CodeVenture, users will see:

  • A green "CV" badge indicating CodeVenture authentication
  • Their username displayed next to the badge
  • Hover tooltip showing "Logged in as [username] from CodeVenture"

CodeVenture Backend Integration

For production use, CodeVenture needs to provide:

1. JWT Token Generation

// Example JWT payload { "sub": "user_id", "username": "user_name", "iat": 1516239022, "exp": 1516325422, "iss": "codeventure.app" }

2. Token Validation API (Optional)

POST https://codeventure.app/api/auth/validate Authorization: Bearer {token} Content-Type: application/json { "username": "user123", "userId": "12345" } // Response: { "valid": true, "username": "user123", "userId": "12345", "profile": { "displayName": "User Name", "avatar": "avatar_url" } }
Security Note: The current implementation uses basic token validation for development. For production, enable API validation by setting DEFAULT_CONFIG.requireAPIValidation = true in codeventure-auth.js.

Configuration

Authentication behavior can be configured in packages/scratch-gui/src/lib/codeventure-auth.js:

export const DEFAULT_CONFIG = { apiUrl: 'https://codeventure.app/api/auth/validate', tokenExpiration: 24 * 60 * 60 * 1000, // 24 hours requireAPIValidation: false, // Set to true in production cleanUrlAfterAuth: true };

Testing

To test the integration:

  1. Build the Scratch Editor: npm run build
  2. Serve the built files locally
  3. Visit the URL with authentication parameters
  4. Check that the user appears authenticated in the menu bar
  5. Verify that URL parameters are cleaned after authentication
